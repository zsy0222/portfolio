# Chenmu Songti web subsets

Derived from Noto Serif SC Regular (Google Fonts v36), distributed under SIL OFL 1.1; see OFL.txt.

Source: https://fonts.gstatic.com/s/notoserifsc/v36/H4cyBXePl9DZ0Xe7gG9cyOj7uK2-n-D2rd4FY7SCqyWv.ttf
Upstream: https://github.com/notofonts/noto-cjk
License source: https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt

The font was subsetted with FontTools, hints removed, and converted to WOFF2. Internal names were changed to Chenmu Songti. No outlines were redesigned. The 7,098 retained CJK and full-width glyphs cover existing repository text plus GB2312. `core` covers existing repository text; `common` splits remaining GB2312 characters. Rare characters outside these ranges fall back to installed Songti SC, SimSun, Noto Serif SC, Source Han Serif SC, or a system serif font. The browser loads only files needed for the text it encounters. Songti SC / SimSun are preferred when installed. Latin lettering remains in DM Sans / Georgia, and code remains monospaced. The regular face uses the browser's normal weight synthesis for bold labels.
